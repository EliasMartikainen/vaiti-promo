## Mikä on VAITI?

VAITI (Vainajatietojärjestelmä) on selainpohjainen SaaS-järjestelmä hautaussäilytyspaikkojen hallintaan suomalaisille evankelisluterilaisille seurakunnille.

Järjestelmä korvaa manuaalisen koordinoinnin — puhelut, Excel-taulukot ja WhatsApp-ryhmät — reaaliaikaisella tilannekuvalla. Käytössä Meri-Lapin alueella.

## Tämä repositorio

Staattinen HTML/CSS/JS-myyntisivu, joka on hostattuna GitHub Pagesin kautta.

### Tiedostot

| Tiedosto | Kuvaus |
|---|---|
| `index.html` | Pääsivu (myyntisivu) |

### Teknologiat

- HTML5 / CSS3 / Vanilla JavaScript

- [Lucide](https://lucide.dev/) — ikonit
- [Outfit](https://fonts.google.com/specimen/Outfit) — fontti (Google Fonts)
- [FormSpree](https://formspree.io/) — yhteydenottolomake
- GitHub Pages — hosting
